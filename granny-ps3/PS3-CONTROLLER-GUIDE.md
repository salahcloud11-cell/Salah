# دليل التحكم بـ PS3 في Granny (نسخة الـ mod)

## ⚠️ خطوة ضرورية قبل التثبيت

1. **تأكد أنك محمّل النسخة الكاملة (single APK)** — شوف `README.md` فقرة
   "Native libraries". نسخة الـ base بوحدها ما كتفتحش اللعبة.
2. **احذف (uninstall) لعبة Granny الأصلية أولاً** — النسخة المعدّلة موقّعة بتوقيع
   مختلف، أندرويد ما غادي يقبل التثبيت فوق الأصلية (غادي تعطيك "مشكل في الباكدج" / App not installed).
3. بعد الحذف، ثبّت APK الجديد (سمح بـ "التثبيت من مصادر مجهولة" إلى طلبها منك).
4. **فرمّل (pair) اليد قبل ما تفتح اللعبة** — شوف الفقرة الجاية.

## ✅ فرملة اليد (DualShock 3)

### الطريقة 1: USB OTG (الأسهل، مضمونة)

1. ركّب اليد للتيليفون بكيبل **USB OTG**.
2. افتح اللعبة — غادي يبان ليك toast: *"PS3 controller connected"*.
3. صافي، لعب 🎮.

### الطريقة 2: Bluetooth

يد PS3 ما كتخدمش بالبلوتوث مباشرة مع أندرويد (protocol خاص بيها)، خاصك:

1. ثبّت تطبيق **SixaxisPairTool** (PC) أو **SixaxisPairer** وحدّد الـ master address
   ديال التيليفون عبر USB مرّة وحدة.
2. من بعد فرمل اليد بالبلوتوث مع التيليفون (تطبيق **Sixaxis Controller** كيساعد بزاف).
3. **تأكد أنها متصلة قبل ما تفتح اللعبة**، وجرّب الأزرار فالقائمة.

> ملاحظة: إلى برمتي اليد **أثناء** اللعب وما تحرّك والو، **اقفل اللعبة كاملة**
> (force stop من الإعدادات) وعاود فتحها واليد متصلة.

## 🎮 التوزيع ديال الأزرار (كامل!)

| زر اليد | الوظيفة فاللعبة |
|---|---|
| **العصا اليسرى (L3)** | الحركة — بحال joystick البيضاء (أنالوغ، 360°) |
| **D-Pad** | الحركة — رقمية (8 اتجاهات)، مدموجة مع العصا اليسرى |
| **العصا اليمنى (R3)** | التدوير / التخمام (look) — يمين/يسار/فوق/تحت، مستمر |
| **✕ CROSS** | اليد 🤚 — هز / استعمل / حل (grab / use / open) |
| **R1** | اليد 🤚 — نفس الشي (زر سريع بلا ما تحرّك صبعك) |
| **R3 (كليك العصا اليمنى)** | اليد 🤚 — نفس الشي |
| **○ CIRCLE** | زر الوسط السفلي — Drop / Use / Place / Shoot (القوس) / Spray |
| **R2 (الزناد)** | نفس زر CIRCLE — الزناد منطقي للقوس والـ spray |
| **□ SQUARE** | زر الوسط — التخبية والخروج (تحت الناموسية، الخزانة...) + أي زر كيبان فالوسط |
| **L2 (الزناد)** | نفس زر SQUARE |
| **△ TRIANGLE** | الوقوف / القرفصاء (أيقونة الشخص أعلى اليسار) |
| **L1** | الوقوف / القرفصاء — نفس الشي |
| **L3 (كليك العصا اليسرى)** | الوقوف / القرفصاء — نفس الشي |
| **SELECT** | الوقوف / القرفصاء — نفس الشي |
| **START** | القائمة / pause (أعلى اليمين) |
| **L3 + R3 بجوج** | تشغيل / طفيان الـ mapping (إلى بغيتي تخدم غير باللمس) |

- **العصا اليمنى**: خدمة بـ "ضربات متكررة" (re-stroke كل ~140ms) باش التدوير يكون
  مستمر — حرّكها وخليها، الكاميرا غادي تبقى كتدور. الـ dead zone كبير شوية (0.28)
  باش ما تدورش بوحدها.
- **اللمس باقي خدام**: يد + لمس بجوج فدقة وحدة، ما كاين حتى مشكل.
- **القوائم (menus)**: الأحسن تخدم باللمس فالقوائم الرئيسية — الـ mapping مصاوب
  للعب داخل الدار. (START كيحل الـ pause.)

## 🔧 إلى ما خدمتش اليد

1. تأكد أنها **متصلة قبل ما تفتح اللعبة** (طفيها وزوّجها من جديد).
2. شغّل اللعبة — إلى ما تحرّكتش، **اقفل اللعبة كاملة** (force stop من
   Settings > Apps > Granny) وعاود فتحها بعد ما اليد متصلة.
3. جرّب USB OTG باش تحيّد الشك من البلوتوث.
4. تأكد أن الـ mapping مشعّل: كليكي **L3+R3** وشوف الـ toast (ON/OFF).
5. العصا اليمنى ما كتدورش؟ حرّكها للأخير (dead zone 0.28) وتأكد أنك فاللعب ماشي فالقائمة.
6. تأكد من الملف (md5/sha256 فـ `README.md` ديال هاد المجلد).

## 🕹️ نصائح

- يد PS3 بالبلوتوث: إلى سالا الباتري، عاود الاتصال **قبل** ما تكمل اللعب.
- القوس (crossbow): صوّب بالعصا اليمنى وtir بـ **R2 / ○**.
- التخبية تحت الناموسية: قرّب، شوف لتحت، وكليكي **□**.
- القرفصاء قبل ما تدخل بلايص ضيقة: **△ / L1**.
