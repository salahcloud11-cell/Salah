## ⚠️ التثبيت (خطوة زراء)

1. **احذف (uninstall) اللعبة الأصلية أولاً** — التوقيع مختلف، أندرويد ما غاديش يقبل التثبيت فوقها.
2. ملفات OBB باقية فـ `Android/obb/` (تقدم اللعبة يتمسح مع الحذف).
3. ثبّت الـ APK الجديد.
4. **فرمّل (bapair) اليد قبل ما تفتح اللعبة.**
